# 📝 My Blog App (Node.js + Express)

## 📌 Features

- ✅ Create blog posts
- ✏️ Edit posts
- 🗑 Delete posts
- 📅 Automatic date & time stamping
- 🎨 Clean card-based UI
- 📱 Fully responsive design (mobile friendly)

---

## 🛠 Tech Stack

- Node.js
- Express.js
- EJS (Embedded JavaScript templates)
- HTML5
- CSS3

---
